# 格式契约（四层产物）

> 所有编号、字段、上限都是硬契约。改动必须同步 `scripts/contract.py`、`scripts/distill.py` 与 `scripts/verify.py`。

## 1. 蒸馏稿（模型产出，子项目交付物）

文件名：`distill/E##_标题.md`。这是「小说 → 可拍剧本」的中间层，也是可以单独交给编剧/美术的成品。

```md
# E01 霹雳外传第一集：叶小钗传奇

- 源行范围：R0001–R0101
- 本段主线：叶小钗隐居垂钓，秦假仙与业途灵偶遇并欲攀附，命随刀劫夺九龙翡翠引发唐皇教追查。

## 角色
| 角色 | 原文称呼 | 身份 | 首次 | 标志物 |
|---|---|---|---|---|
| 叶小钗 | 小钗、钗儿 | 剑客 | R0003 | 刀疤脸、背后刀剑、长袍 |
| 秦假仙 | 大仔 | 江湖人 | R0005 | 斗笠、钓竿 |

## 剧情线
- 起：叶小钗独自在天机湖垂钓，秦假仙与业途灵在对岸钓鱼并认出叶小钗。
- 承：业途灵欲运功过湖攀附，秦假仙以记者名气为由拖延。
- 转：命随刀截杀护箱人，夺走九龙翡翠，护标者逃回唐皇教请罪。
- 合：天荒推测是宇文山庄所为，教皇下令追查。
- 冲突：命随刀劫宝与护标人的对抗；唐皇教追查失宝真相。

## 场景卡
### E01-S01 天机湖畔 · 日
- 场景：天机湖畔
- 时段：日
- 出场：叶小钗、秦假仙、业途灵
- 剧情：叶小钗湖中垂钓，秦假仙与业途灵在对岸发现他，业途灵想运功过湖打招呼。
- 镜头密度：中
- 可拍画面：
  - R0003 叶小钗独自行走，风扬起长袍
  - R0005 秦假仙与业途灵戴斗笠走来
  - R0011 业途灵手指对岸
- 台词：
  - E01-L001 | 业途灵 | 大仔，七重冥王及魔魁之女都死了 | 无聊
```

校验规则（`distill.validate`）：

| 项 | 规则 |
|---|---|
| 角色表 | `## 角色` 表格，至少 1 行；`首次` 是 `R####` 且落在本段范围 |
| 剧情线 | 起／承／转／合 四段必填；`本段主线` ≤40 字 |
| 场景卡 | `E##-S01` 起连续，不跳号不重复 |
| 可拍画面 | 每条 `- R#### 动作`，6–25 字；不得含心理/因果/转场/评价词 |
| 台词 | `E##-L001` 起全段连续、唯一；说话人非空，建议在角色表内 |
| 行号 | `R####` 必须落在本段源行范围内 |
| 英文 | 除 `ALLOWED_EN`（拟声/台标）外不得出现 |

跑完全部段落由 `distill.aggregate` 汇总 `00_角色总表.md`、`00_剧情线.md`、`characters.json`、`plot.json`。

## 2. 语义 md（程序投影，人也要能读）

文件名：`semantic/E##_标题.md`。由蒸馏稿 `distill.project` **确定性投影**：`可拍画面` 改名为 `叙述素材`，其余字段原样搬。下游 `plan` 只读这一层。

> `E##` 是**分段号**（默认 2000 字/段，切点落在换行），不是原书集号。一段 ≈ 一条 60 秒视频的原料。源文溯源只认 `R####` 行号，不认原书集号。

```md
# E02 第二集：圈套

- 原标题：霹雳外传第二集：圈套
- 源行范围：R0288–R0331

### E02-S01 断生崖 · 龙虎初斗
- 场景：断生崖
- 时段：日
- 出场：命随刀、唐龙剑云、情海过客
- 剧情：命随刀在崖顶拦下唐龙剑云，两人言语交锋后动手，情海过客旁观未出手。
- 镜头密度：高（建议 1 条 60 秒视频）
- 叙述素材：
  - R0290 断生崖上龙虎斗，命随刀单刀直入
  - R0292 刀光贴着崖壁擦过，碎石滚落深谷
- 台词：
  - E02-L001 | 唐龙剑云 | 哈哈哈哈..相传命随刀刀法盖世 | 傲然
  - E02-L002 | 命随刀 | 试过便知 | 低沉

### E02-S02 ……
```

校验规则（`contract.validate_semantic`）：

| 项 | 规则 |
|---|---|
| 场景块 | `E##-S01` 起连续，不跳号不重复 |
| 台词 | `E##-L001` 起全段连续、唯一 |
| 行号 | `R####` 必须落在本段源行范围内，且每条素材至少一个 |
| 必填字段 | 场景、出场、剧情、叙述素材；台词栏非空则必须有台词行 |
| 英文 | 除 `ALLOWED_EN`（拟声/台标）外不得出现 |
| 音量标签 | 语气列 ≤8 字，`语气：狂傲` 这类前缀会被自动剥掉 |

## 3. 分镜计划（模型产出，给程序读）

文件名：`plans/E##_plan.json`。

```json
{
  "episode": "E02",
  "episode_title": "第二集：圈套",
  "videos": [
    {
      "title": "断生崖龙虎斗",
      "src": "E02-S01–S04 / R0288–R0311",
      "logline": "命随刀崖顶拦路，与唐龙剑云一言不合动手。",
      "scene": "断生崖",
      "characters": ["命随刀", "唐龙剑云", "情海过客"],
      "props": [],
      "segments": [
        {"i": 1, "action": "命随刀横刀立于崖沿，衣袍向外掀起", "dialogue": null},
        {"i": 2, "action": "唐龙剑云踏上崖顶，右手按上斧柄", "dialogue": {
          "speaker": "唐龙剑云", "delivery": "傲然",
          "text": "相传命随刀刀法盖世", "line": "E02-L001"}}
      ]
    }
  ]
}
```

| 字段 | 约束 |
|---|---|
| `videos` | 恰好 `want` 条（默认 `round(块数/9)`，钳 1–4） |
| `scene` | 1 个，必须在 `SCENES` |
| `characters` | 必须在 `CHARS`；`props` 在 `PROPS` |
| `characters + props` | ≤5（加场景共 6 槽） |
| `segments` | 恰好 12 项，`i` 1–12 连续 |
| `action` | 6–25 字，无侧面描写词、无英文、不以「说/道/喊」开头 |
| `dialogue` | `null` 或对象；`speaker` 在 `characters` 内且非哑角 |
| `delivery` | 2–4 字语态标签（油滑/悍然/冷讥/急切/沉痛） |
| `text` | ≤21 字（标点算字） |
| `line` | 逐字引用填真实 `E##-L###`；压缩改写填 `""` |

`line` 的两种合法状态：

- **逐字引用**：`text` 与 `sem_index[line]` 去标点后互为子串 → 保留原编号。
- **压缩改写**：文本对不上 → `sanitize_plan` 清空 `line`，装配时补 `E##-C###`，保证可追溯且不冒充原文。

## 4. 1 分钟分镜 JSON（程序装配）

文件名：`1min/V##_标题.json`。

```json
{
  "id": "V01", "episode": "E02", "title": "断生崖龙虎斗",
  "scene": "断生崖", "src": "E02-S01–S04 / R0288–R0311",
  "logline": "……", "duration_sec": 60, "segments_count": 12,
  "cast": {
    "scene": {"slot": "断生崖", "kind": "scene", "picture": 1, "ref_file": "image1.jpg"},
    "characters": [
      {"slot": "命随刀", "kind": "char", "picture": 2, "ref_file": "image2.jpg"},
      {"slot": "唐龙剑云", "kind": "char", "picture": 3, "ref_file": "image3.jpg"}
    ],
    "props": []
  },
  "segments": [
    {"i": 1, "time": "0.0–5.0s",
     "p": ["断生崖", "命随刀"],
     "b": [["A", "命随刀横刀立于崖沿，衣袍向外掀起"]],
     "beats": [{"t": "0.0–5.0s", "type": "action",
                "text": "命随刀横刀立于崖沿，衣袍向外掀起"}]}
  ]
}
```

- `p`：本段上镜槽位，`p[0]` 恒为场景。
- `b`：拍点原始数组，`["A", 动作]` 或 `["D", 说话人, 语气, 台词, 编号, 附加动作]`。
- `cast.picture`：**整条视频固定**，按 `p` 首次出现顺序排，scene 恒 1。

## 5. 工作流 JSON（程序装配，与模板同构）

文件名：`workflow/V##_标题.json`。不改模板结构，只写以下位置：

| 位置 | 内容 |
|---|---|
| 12 个 `AICG3D_H3SequenceSegment.prompt` | 三通道：`[C]` 构图/参考图绑定 → 画面动作 → `<d>[Chinese]台词</d> delivery:` |
| 同节点 `inline_media_state` | 12 段同一组 `image1..6.jpg` |
| 同节点 `minimax_h3_prompt_reference_doc` | `mention`（`<Picture k>`）+ `dialogue`（`[Chinese]…`）双部分 |
| `AICG3D_H3CharacterVoiceLibrary` | 按出场角色注册，`picture_index` 与参考槽对齐 |
| `AICG3D_H3SequenceGlobal` | 风格串、分辨率 620x348、16:9、24fps、输出目录 |
| `AICG3D_H3FinalSequenceUpscale` / `SaveVideo` | 文件名前缀、1152×640 |

节点按 `type` 定位（`workflow.resolve_nodes`），不写死 id；换模板只需保证类型一致、段节点 12 个。
