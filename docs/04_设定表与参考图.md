# 设定表与参考图

设定表 `work/tables.py` 是整条链路唯一的「世界观来源」。模型只能从这张表里选场景、人物、道具，选不到就报错。

## 1. 槽位顺序 = 参考图编号

```
Picture 1   ← SCENES 第 1 项
Picture 2   ← CHARS  第 1 项
...
Picture k   ← 依次往下，场景 → 人物 → 道具
```

`assemble` 的 `cast.picture` 与 `workflow` 的 `<Picture k>` 都按这个顺序生成。**表里改顺序，产物编号就整体平移**，所以定表后尽量不要插队；必须插队就重跑 `assemble,workflow`。

## 2. 字段

### SCENES

```python
SCENES = {
    "断生崖": ("断生崖·崖顶平台", "P04_断生崖",
        "主光为画面正上方顶光（约5800K），崖缘反白光，崖下深谷压成灰黑，风把衣袍向外掀，曝光跨段锁定。",
        "高空风鸣、碎石坠落深谷、衣袍猎猎、鸦啼"),
}
```

- key 是模型能选的**唯一名字**，也是台词/动作里用来定位的字符串。
- 第 2 项文件名只作占位，正式参考图按 `P<槽号>_<key>.png` 命名。
- 光照必须写：**方向 + 色温 + 明暗关系 + 跨段锁曝光**。12 段共用一张场景图，光照含糊会导致每段观感不一致。
- 同一地点多种叫法写进 `LOCATION_HINTS`，不要在建两个场景槽。

### CHARS

```python
CHARS = {
    "命随刀": ("命随刀",
        "中年男性，方脸刚毅，短须，眉间竖纹；深灰劲装束皮护腕，背负宽背大刀，刀柄缠旧布。",
        "黑短发硬直，鬓角带灰，发丝干燥"),
}
```

- 外貌只写看得见的：年龄、体态、脸型、服饰、武器、随身物。
- 发质单独一条：颜色、发型、干湿、蓬松度、动态。
- 不要把性格、关系、过往写进去——模型会把它们画成表情或字幕。

### PROPS

```python
PROPS = {
    "十方灵动": ("灵剑十方灵动", "P十方灵动", "古剑，白鞘刻灵纹，出鞘剑身泛淡蓝光，剑鸣清越。"),
}
```

只给**反复出现、需要保持外观一致**的关键物件建槽。一次性道具不要进表，写进动作里即可，否则白占槽位。

### VOICES

```python
VOICES = {
    "命随刀": ("mingsuidao", "命随刀", "中年男性声音，低沉刚硬，短句重音，怒时带沙哑。",
               "Chinese", "middle_age", "male", "low", "natural"),
}
```

- `role_id` 全局唯一，英文小写。
- `age`：`young_adult / adult / middle_age / elder`
- `gender`：`male / female / unknown`
- `pitch`：`very_low / low / medium_low / medium / medium_high`
- `pace`：`slow / natural / fast`

### MUTE / SPEAKER_ALIAS / LOCATION_HINTS

```python
MUTE = ["叶小钗"]                     # 出场但绝不说话
SPEAKER_ALIAS = {"轿内人": "宇文知日", "老者": "宇文知日", "教皇": "唐龙剑云"}
LOCATION_HINTS = {"江边": "天机湖", "湖畔": "天机湖", "庄院": "宇文山庄"}
```

- `MUTE` 会同时约束计划和装配：哑角若被安排台词，校验报错，装配直接删条。
- `SPEAKER_ALIAS` 只影响说话人归一，不改变语义 md 原文。
- `LOCATION_HINTS` 直接拼进 plan 提示词；原文地点越杂，这张表越要全。

## 3. 怎么快速建表

```bash
python3 scripts/make_tables.py --semantic work/semantic --out work/tables.py
```

它会统计 `出场` 字段与说话人，生成一份占位表。之后必须人工补：

1. 场景光照与环境音
2. 人物外貌与发质
3. 音色四要素
4. 别名与地点映射

占位表能跑通链路，但画面会「没有导演」：光照空、外貌空，模型只能自由发挥。

## 4. 参考图命名

```
work/refs/
  image1.jpg   ← Picture 1，场景
  image2.jpg   ← Picture 2，第 1 个出场人物
  image3.jpg   ← Picture 3，第 2 个出场人物
  ...
```

- `cast.ref_file` 已写好 `image<k>.jpg`，按它替换即可。
- 每条视频的槽位组合不同，同一张 `image2.jpg` 在不同视频里可能指不同角色——**按视频目录分开放**，不要把全片参考图混在一处。
- 参考图要求：单人/单场景、正面或 3/4 侧、光线均匀、背景干净、分辨率一致。
